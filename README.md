# Nexus — موقع تنزيل تطبيق قراءة المانجا والمانهوا

## التشغيل
ضع ملف `works.json` بجانب `index.html` ثم افتح الموقع عبر أي خادم محلي أو استضافة.

> ملاحظة: `fetch()` لا يعمل مع `file://` — شغّل عبر خادم بسيط:
> ```
> npx serve .
> # أو
> python -m http.server 8080
> ```

## ما يقرأه الموقع من works.json
يقرأ السكريبت فقط حقلين من كل عمل (يتعامل مع أشكال متعددة تلقائياً):
- **الكافر (الصورة):** `cavar` أو `cover` أو `image` أو `img` أو `poster` أو `thumbnail`
- **اسم العمل:** `name` أو `title`

ويدعم الملف بصيغ: مصفوفة مباشرة، أو `{ "works": [...] }`، أو `{ "data": [...] }`، أو `{ "list": [...] }`.

## الصفحات الديناميكية (SEO)
- كل عمل يحصل على رابط: `index.html?work=اسم-العمل`
- عند دخوله تظهر صفحة: كافر العمل + الاسم + "يرجى تنزيل التطبيق" + شعار Nexus + زر التنزيل + مميزات التطبيق.
- تُحدَّث `title` و `meta description` و `og:` ديناميكياً، وتُضاف بيانات منظمة JSON-LD (Book / ItemList) لتحسين ظهور جوجل.

## روابط التنزيل
عدّل روابط المتاجر داخل `js/app.js` في دالة `bindDownloadModal` (ابحث عن `apps.apple.com` و `play.google.com` واستبدلها برابط تطبيقك الفعلي).
